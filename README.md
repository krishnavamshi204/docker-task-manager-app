# 🚀 Docker Task Manager App

## 📌 Description
A simple Task Manager API built using Node.js and MongoDB, fully containerized using Docker.

---

## 🛠 Tech Stack
- Node.js (Express)
- MongoDB
- Docker & Docker Compose

---

## ⚙️ Features
- Add tasks
- View all tasks
- REST API
- Containerized setup

---

## ▶️ Run Project (Docker)

```bash
docker compose up --build
